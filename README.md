## 🌟 Описание проекта

**Network & Ping Watchdog** — это сетевой сторожевой таймер и анализатор стабильности домашнего интернет-соединения.

Если интернет дома внезапно «лагает» или пропадает, программа мгновенно определяет виновника:
1. Завис ли домашний Wi-Fi роутер (`192.168.1.1`);
2. Упал ли магистральный DNS (`1.1.1.1` или `8.8.8.8`);
3. Произошел ли сбой на стороне конкретного веб-сервиса (Яндекс, GitHub, Discord);
4. Или проблема на физической линии интернет-провайдера.

### Ключевые возможности:
- ⏱ **Замер задержки в миллисекундах каждые 2 секунды** без необходимости запуска громоздких систем.
- 📉 **Живой мульти-линейный график (Chart.js)**: наглядная картина скачков пинга и микрофризов.
- 🚨 **Автоматический журнал инцидентов (Incident Log)**: точная поминутная фиксация каждого обрыва связи для доказательств в техподдержку провайдера.
- 📊 **Расчет потерь пакетов (Packet Loss %)** и среднего времени отклика для каждого узла.
- ➕ **Добавление собственных серверов**: возможность отслеживать пинг до серверов любимых игр (CS2, Dota, Minecraft) или рабочих VPS.

## 🛠 Стек технологий

- **Backend**: Python 3.11+, FastAPI, Uvicorn, asyncio, низкоуровневые TCP-handshake сокеты
- **Frontend**: HTML5, Tailwind CSS (стиль NOC Data Center), Chart.js
- **Архитектура**: Фоновый асинхронный воркер без блокировки интерфейса

## 🖥 Зачем этому проекту нужен выделенный сервер 24/7?

Сетевой watchdog приносит максимальную пользу только при непрерывной круглосуточной работе:

1. **Беспристрастный аудит интернет-провайдера 24/7**:
   - Провайдеры часто списывают ночные обрывы или потери пакетов на проблемы роутера пользователя. Сервер накапливает неопровержимый лог стабильности за 30 дней с точными миллисекундами сбоев.
2. **Автоматическая перезагрузка роутера при зависании (Auto-Healing)**:
   - Сервер 24/7 при фиксации 100% потери пакетов до шлюза может через смарт-розетку или SSH отправить команду на перезапуск роутера, восстанавливая домашний интернет автоматически.
3. **Telegram-оповещения о падении домашней сети**:
   - Если сервер подключен через резервный 4G-модем, при падении основного оптоволокна он мгновенно отправляет уведомление родителям: «Внимание: обрыв кабеля провайдера в квартире».
